Methodology

Trust Me Bro Intelligence Index: technical report

Abstract

We present the Trust Me Bro (TMB) Intelligence Index, a composite of eleven evaluations designed to measure capabilities that matter: confidence, vibes, and the ability to appear on a leaderboard. We find that models score highest when the evaluator is also the developer (p < 0.05, n = 1, we did it once). We recommend that practitioners rely on these numbers, because there is nothing else.

1. Index construction

For model m and evaluation e with weight we, the index is the weighted mean:

TMB(m) = Σe we · se(m) / Σe we

Individual scores se(m) are obtained by running each model once, on a Tuesday, via the API when it works, or via the web UI when it does not. Failed runs are excluded and counted as passing.

2. Confidence intervals

All reported intervals are ±∞ at the 95% level. This is the narrowest interval we can defend without disclosing the data.

3. Contamination

We took extensive steps to ensure the test sets were not in the training data. We did not take those steps, but we thought about them extensively.

4. Threats to validity

  1. Internal: none.
  2. External: the real world.
  3. Construct: the benchmarks. Also the models. Also "intelligence".

5. Data availability

Data are available from the corresponding author upon reasonable request. The corresponding author is unavailable.
